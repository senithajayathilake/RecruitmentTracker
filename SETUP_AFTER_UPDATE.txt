RECRUITMENT TRACKER - FINAL VERSION

HOW TO USE THIS VERSION

1. BACK UP YOUR CURRENT PROJECT FIRST.
2. Close Visual Studio.
3. Keep your existing .git folder if you want to preserve Git history.
4. Replace the project source files/folders with the contents of this final folder.
5. Open RecruitmentTracker.sln in Visual Studio 2022.
6. Build -> Rebuild Solution.
7. Press F5.

IMPORTANT DATABASE NOTE
-----------------------
This university prototype uses EnsureCreatedAsync instead of EF migrations.

The first time this final version runs, it checks whether your old LocalDB
database contains the final Interviews, InterviewFeedbacks, Notifications and
new application/vacancy columns.

If not, RecruitmentTrackerDB is deleted and recreated automatically.

BACK UP ANY TEST DATA YOU CARE ABOUT BEFORE RUNNING THE FINAL VERSION.
