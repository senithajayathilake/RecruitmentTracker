HIGHER FLOW - FINALIZED WEBSITE BUILD

This build is based on the stable RecruitmentTracker feature set and includes:
- Full recruitment workflows from the previous version
- Restored clean black/yellow glass theme
- Public Home page
- Working public Opportunities page
- Working About page
- Working Contact page + form confirmation
- Styled candidate registration and login
- HR / Candidate / Interviewer / Hiring Manager dashboards
- Vacancy, candidate, interview, feedback, comparison, reports and role management
- Fixed Tools dropdown stacking
- Cloud-safe Program.cs (does not delete the database on startup)

IMPORTANT:
1. Keep your old project as a backup.
2. Replace the project folder with this one.
3. Copy your .git folder from the old project if you want to keep GitHub history.
4. Open RecruitmentTracker.sln.
5. Build > Rebuild Solution.
6. Run and press Ctrl+F5 in the browser.

The .NET SDK is not available in the ChatGPT working environment, so the final compile must be verified in Visual Studio.
